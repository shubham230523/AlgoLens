# AlgoLens 🚀

**AlgoLens** is a high-performance, production-ready educational platform designed to make algorithms come alive. Built with React Native, Expo, and Reanimated, it provides a seamless learning experience across Web, iOS, and Android.

## ✨ Core Pillars

### 1. 🧠 Intelligent AI Tutor & Code Sync
*   **Context-Aware Tutoring**: Our AI Tutor doesn't just chat—it *sees*. It understands the current algorithm state, the specific line of code executing, and the variables involved to provide precise pedagogical help.
*   **Pixel-Perfect Synchronization**: The code viewer automatically highlights and scrolls to the exact line being visualized, ensuring the bridge between theory and implementation is never broken.

### 2. 🌳 Advanced Visualization Engine
*   **Dynamic Tree & Array Rendering**: Seamlessly visualize hierarchical data with our auto-layout BST engine or observe array-based algorithms with adaptive bar charts.
*   **Universal Switching**: The engine automatically detects the algorithm type, switching between optimized Array and Tree visualizations instantly.

### 3. 🗺️ Curated Learning Journeys
*   **Structured Paths**: Master topics through curated journeys like "Sorting Master" and "Search Pro."
*   **Progress Tracking**: Stay motivated with real-time progress bars and a visual roadmap that tracks your mastery across every algorithm.

### 4. ⚡ Elite Performance & Scaling
*   **UI-Thread Animations**: Powered by Reanimated, visualizations run at a silky-smooth 60 FPS, offloaded from the JavaScript thread.
*   **Adaptive Scaling**: Whether you're sorting 5 elements or stress-testing with 50, our adaptive layout engine ensures the visualization is always clear and responsive.

### 5. 🌍 Built for Everyone, Everywhere
*   **Fully Offline**: The entire engine, code highlighter, and learning paths are bundled. Learn anywhere—no internet required.
*   **Inclusive Design**: Gold-standard accessibility with full Screen Reader support, dynamic ARIA labels describing the algorithm state, and a system-aware "Reduce Motion" mode.
